## 🚀 Key Platform Features

We built Esports Arena with high performance, top-tier styling, and functional completeness in mind:

### 🔐 Stateless Authentication
* Secure registration & login system driven by **Spring Security** and **JWT (JSON Web Tokens)**.
* Interactive **profile picture uploading** via multipart forms with live preview capabilities in the user interface.
* Strong cryptographic password protection via **BCrypt**.

### 💳 Atomic Virtual Wallet
* Full financial tracker integrated directly into the dashboard.
* Handles transactional operations (`DEPOSIT`, `WITHDRAWAL`, `TOURNAMENT_FEE`, `PRIZE`) atomically to prevent race conditions.
* Real-time header balance updates synchronized with backend actions.

### 🎮 4vs4 Tournament Hub
* Detailed screens displaying ongoing and upcoming 4vs4 tournaments with adjustable entry fees and prize distribution models.
* Dynamic bracket views and team formation flows.
* Live-streaming interfaces and match tracking modules.
